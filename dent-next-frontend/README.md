# Dent Ops - Next.js Frontend (starter)

This folder contains a small Next.js + TypeScript starter that reproduces the admin board UI (views sidebar, lanes, and cards).

Quick start

1. Install dependencies

```bash
npm install
```

2. Run dev server

```bash
npm run dev
```

Open http://localhost:3000

Notes
- The UI is client-side only and uses sample data in `pages/index.tsx`.
- Next steps: wire an ASP.NET Core API, add authentication, or convert components to fetch live data.
